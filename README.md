# Unit Converter - Spring Boot

A web-based Unit Converter application built using Spring Boot and Thymeleaf.

## 🚀 Features

- ✅ Home Page
- ✅ Spring Boot MVC Architecture
- ✅ Thymeleaf Integration
- 🚧 Length Converter (In Progress)
- ⏳ Weight Converter
- ⏳ Temperature Converter

## 🛠️ Tech Stack

- Java 21
- Spring Boot
- Thymeleaf
- HTML5
- CSS3
- Maven

## 📚 Learning Goals

- Spring Boot MVC
- Dependency Injection
- Thymeleaf
- Service Layer
- Git & GitHub
- Backend Development
